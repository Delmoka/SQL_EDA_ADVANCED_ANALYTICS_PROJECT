SQL Exploratory Data Analysis & Advanced Analytics Project

Project Overview

This project demonstrates a complete end-to-end SQL Data Analytics workflow using a relational database. The objective is to transform raw business data into actionable insights through database exploration, exploratory data analysis (EDA), advanced analytics, customer segmentation, performance analysis, and reporting.

The project follows a structured analytics framework commonly used by Business Intelligence Analysts and Data Analysts to understand business performance and support decision-making.
---

THE PROJECT CONTAINS 2 PHASES 
Phase 1: Exploratory Data Analysis (EDA)
Phase 2: Advanced Analytics
